# Praveen Kumar Portfolio

Static HTML, CSS, and JavaScript portfolio site.

## Run locally

From the project root:

```powershell
py -m http.server 5500
```

Open `http://localhost:5500`.

## Vercel deployment

Import the repository into Vercel with these settings:

- Framework Preset: Other
- Root Directory: project root
- Build Command: None
- Output Directory: None
- Install Command: None

The site has no build step. `index.html`, `style.css`, and `script.js` are served directly from the repository root.

## Important paths

- Resume: `/resume/Praveen_Kumar_Resume.pdf`
- Certificates: `/certificates/`
- Images: `/images-upload/`
- Public assets: `/public/`
